UI - тесты веб приложения https://qa-stellarburgers.education-services.ru

Локаторы - в папке locators/, разбиты по страницам
Страницы - в pages/ (вкл. base_page), разбиты по функции 
Есть фикстура для драйвера с кроссбраузерным тестированием (Mozilla Firefox и Chrome)
Урлы хранятся в отдельном файле urls.py
Тесты - в tests/, разбиты по страницам
В data.py - переменная для правильного тестирования отдельных страниц в разных браузерах (н-р, для обхода оверлея в Mozilla Firefox)
